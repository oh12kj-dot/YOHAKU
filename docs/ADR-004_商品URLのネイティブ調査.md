# ADR-004 商品URLのネイティブ調査

2026-11-08。ADR-003の後続。Sol Mediumの設計契約に基づく初期範囲はFLYMEeの掲載情報調査。商品写真からの3D生成・モデル採用・公式寸法の照合は別工程として残す。

## 境界と表示

- 純粋なURL検査・HTML抽出・結果JSONはYohakuCoreのProductSource。通信・取消・画面はYohakuのProductResearch/Slate。Node/Python/ブラウザーを配布アプリの実行環境にしない。
- HTTPSの `flymee.jp/product/数字/` と任意の数値pi_id一つだけを許可。認証情報・ポート指定・フラグメント・別ホスト・別クエリーを拒否する。
- UE標準Curlは転送を追跡するため、本機能はWindows WinHTTPで転送禁止を送信前に設定。Cookie/自動認証を無効にし、標準の証明書・ホスト名検証を保持。画像URLは記録だけで取得しない。
- Workerで接続/受信を行う。受信2MiB上限、12秒の期限と短い段階タイムアウト、同時1件・開始間隔1秒。取消はトークンで行い、実行中の通信待ちが終わるまで再取得を開始しない。
- Completionはゲームスレッドだけで反映し、thread-safeな弱参照、世代番号、URL一致で取消/古い応答/破棄済み所有者を保護する。URL編集で前結果を即時消去。失敗時に前商品の情報を表示しない。
- 元のHTMLバイト列のSHA256、出典URL、UTC取得日時、全体外寸、別仕様注記、仕様ID/名称/一致した写真URLを保持する。`single-source-unverified` / `not-generated` とし、pi_idと仕様IDの対応は推測しない。
- `.spec_area_list._size` の幅/奥行/高さのcm/mmだけを外寸として扱う。欠落・矛盾・範囲外は追加調査エラー。座面/低脚寸法で代用しない。色写真は `張地：名称` の完全一致が必要。
- 調査結果は一時状態。SceneDocument・Dirty・Undo/Redo・既存家具・保存形式を変更しない。取得結果から配置/採用へ自動接続しない。

## 既存コード

workers/importは将来のサーバー用資産として保持し、配布しない。CLI内の重複したHTTP取得は削除しfetchProductへ統一。ネイティブとサーバーの抽出契約は `tests/fixtures/flymee-product.html` で検査する。このHTMLは既存の保存済み参照ページから複製した固定試験資料であり、最新ページの取得成功の根拠にはしない。

## 受入条件

1. URLの迂回・重複クエリー・矛盾する寸法・座面高混同・他色写真代用・不正UTF8・過大本文を拒否する。
2. 実URLを配布exeから取得し、1500×870×820mm・2色・未照合/生成未実施と表示する。取得前後のシーン/Dirty/履歴が同一。
3. 取消・URL編集・古い完了応答・画面/所有者の終了で誤った結果を反映しない。
4. 既存の部屋編集・保存/別プロセス復元を再検査する。通信境界をSol Lowで一度独立レビューする。

本契約はアプリ全体の写実/性能受入、任意商品の3D化、認証/クラウド保存の完了を意味しない。
