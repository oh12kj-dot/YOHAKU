# ADR-006 間取り拡張・生成試作・配置判定

2026-11-08。ユーザーが残タスク1/2/3の実装を指定。Sol Mediumを明示した一つの設計契約と、実機生成の結果を受けた補足に基づく。

- YohakuCoreのSceneDocumentをv2へ移行。部屋ごとに単純な直交多角形、床・壁の安定ID/仕上げ、天井高を持ち、窓/ドアは壁IDと位置・寸法で参照する。重複室・自己交差・壁外/重複開口を全体拒否。変更は一つのスナップショット履歴にする。
- v1を厳格に読み、旧北/南/東/西、仕上げ、家具GUID/姿勢/版を保ってメモリー内で変換。元ファイルは明示保存まで変更しない。未知/欠損アセット、壊れた保存はシーン全体を保持して拒否する。
- 家具の固定2色フィールドを不変AssetVersionId参照へ変更。既存PSFは既存study版として維持する。商品候補ファイルは独立したまま変更しない。
- 写真→形状は既存ローカルComfyUIのHunyuan3Dを、サーバーを開かない別プロセスで実行。固定チェックポイント/入力写真/掲載値/仕様ID/生成条件/出力形状のハッシュを保持する。失敗時にPSFや箱へ代用しない。
- ローカルstudy v2では、実際に写真から生成した形状を「掲載値に合わせた無地の未採用試作」として試し置き可能。背面/隠れた形状/方向は推定、寸法は単一出典、材質未生成を表示し続ける。正式readyへの昇格はD1〜D5/M1〜M6を通した別の不変版で行う。現在のHunyuan形状生成だけでは公式寸法照合・写実素材・品質承認済み配置の完了を意味しない。
- 生成試作はユーザー別のモデル保管先に不変manifestとmeshを保存。v2レイアウトはそのIDとmanifestハッシュを参照し、復元時も形状/画像ハッシュ・座標・外寸を検証する。既存配置を新生成で自動変更しない。
- 家具交換は中心保持または選択した壁の内向き法線からの最小外形距離を保持。沿壁位置、向き、床接地、家具IDを保つ。失効した壁は交換を拒否する。
- 干渉は外形の候補から部品の3D外形へ絞る。生成形状の衝突表現は保守的なボクセル近似。校正済みの厳密形状とは表示しない。壁の開口とドア開閉範囲も検査し、自動縮小/削除しない。
- 通路は指定幅/始点/終点で保守的な格子探索を行い、近似であることを表示する。通行・安全性を保証しない。

実装後、v1変換・v2往復・破損/欠損保持・自己交差/室重複/開口境界・壁距離正/0/負/回転・部品干渉・通路閉塞・Undo/Redo・Shipping復元を検査し、新しい保存/形状境界を一度独立レビューする。
