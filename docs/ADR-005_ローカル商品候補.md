# ADR-005 ローカル商品候補

2026-11-08。ADR-004の調査結果を、部屋とは独立した候補として保存する。

- ユーザーが「候補として保存」を押したときだけ、取得済み結果の全項目を保存する。取得中・取消後・URL変更後の結果は保存しない。
- `%LOCALAPPDATA%/Yohaku/ProductCandidates/candidates.yohaku.json`。試験用の `YohakuCandidateRoot` は部屋の保存先指定とは独立する。
- `yohaku-product-candidates` version1。各候補はGUID・UTC保存日時・ProductSource全体を持つ。同じ出典URL（pi_idを含む）と本文SHA256は重複させない。再保存でも元のID・保存日時・取得内容を変えない。内容変更は別候補。
- 100候補・UTF8で4MiBまで。形式、必須項目、余分な項目、GUID、URLと商品ID、時刻、SHA256、寸法、仕様IDと写真URLを検査する。不正なファイルは部分読込や上書きをしない。元のファイルと読込済み候補を保持し、明示再読込が成功するまで保存を止める。
- 保存時は保存先ごとのWindowsミューテックスを取り、最新ファイルを再読込して追加する。同じ場所のGUID一時ファイルへUTF8/BOMなしで書き、MoveFileExWの置換・書込完了指定で反映。失敗時は元ファイルとメモリーを保持。一時ファイルだけを除去する。LayoutStorageは変更しない。
- 保存済み一覧から再表示するときは通信しない。SceneDocument・Dirty・履歴を変更しない。
- 寸法は未照合、モデルは未生成のまま。既存のPSFモデルとの対応やpi_idと仕様の対応を推測しない。写真URLは参照として保存し、画像をダウンロードしない。削除・編集・正式採用はこの範囲に含めない。

受入は重複防止、複数所有者の追加保持、不正形式と置換失敗時のデータ保持、実URLの保存、別プロセスでのオフライン再表示、部屋への非干渉。新しい保存境界を一度独立レビューする。
