# ADR-003 UE5ネイティブアプリへの切替

2026-11-08。ユーザーのUE5採用と旧実装整理の指示を反映。ADR-002の操作要件を保ち、React/Three.jsを現行クライアントから退役させる。描画だけを外付けする構成にしない。

## 実装契約

- `apps/ue/Yohaku.uproject` を本体とする。撮影用Python実験はアプリにしない。YohakuCoreはmmのシーン・厳格な読込・コマンド/履歴、YohakuはUE描画・入力・Slate UI・ローカル保存を担当。
- 1室の長方形をドラッグ/数値で作成し、床/4壁の安定IDを保持。家具は固定外寸、別色の固定候補版へ交換。mm保存、0.001mm正規化、UE描画時にcmへ変換。床面(x,z)/高さy→UE(X,Y,Z)、yawの符号も明示して検査する。
- ネイティブのローカル形式ではNORTH=z=depth、SOUTH=z=0、EAST=x=width、WEST=x=0とする。旧Web版の保存形式を無断で読み替える移行経路は持たず、サーバー形式との相互変換は後続の接続設計で検査する。
- 配置プレビュー、掴み位置を保つ移動、45度回転、数値入力、複製/削除、カメラと家具の入力分離。ジェスチャー終了で1履歴、Esc中止、Undo/Redo100件とRedo枝破棄。
- バージョン付きJSONの明示ローカル保存/読込。保存置換は一時ファイル経由。破損/未知アセット/不正寸法を全体拒否し、現在のシーンを変更しない。履歴は保存しない。保存状態を表示する。
- PSF v3は検証用候補として専用カタログへ置く。実物校正済み/正式採用とは表示しない。部屋寸法も入力値であり実測済みとしない。接触/はみ出しはcoarse警告で、縮小や削除をしない。
- ネイティブ起動、部屋/仕上げ/家具操作、固定外寸/色交換、取消/カメラ非変更、保存再起動復元、不正ファイルでの状態保全を検査する。実機写実品質/性能の全体受入とは区別する。

## 移行と削除

旧Web実装はネイティブの相当機能確認後に現行ソースと起動経路から除去する。再参照用の旧ソース保管と、商品参照写真・取得根拠・生成来歴・検証画像は保持。商品情報抽出ロジックはサーバー側資産として残す。二つの編集エンジンを並行保守しない。UE素材は必要な参照資産だけを移し、旧実験のスタジオ/旧版/撮影起動処理を本体へ混ぜない。

初期ネイティブ版の対象外: 認証/クラウド保存/DB並行処理/生成ジョブ、公式寸法照合、窓/ドア、多部屋。商品URLの掲載情報取得は後続のADR-004で実装。自動3D生成や公式照合を実装済みと扱わない。

## 現在の検証

通常配布をShippingへ変更する。Development版でUE TraceのTCP待受け `0.0.0.0:1985` を観測したため、エンジン標準で開発用Traceを含まないShippingを使う。EditorはDevelopmentのまま。Windowsの許可ルールや通知設定は変更しない。切替の根拠と配布版の回帰試験は `artifacts/native-network-validation.md` に記録する。

初期Development版でネイティブAutomation4件（シーン/商品抽出/非同期結果の状態/候補保存）、サーバー商品抽出13件、配布exeのランタイムAPI/入力イベント/プレビュー確定ハンドラー26項目と別プロセス復元4項目が成功。ネイティブ保存と不正読込の境界、および商品調査の通信/生存期間の境界は独立したSol Lowレビューでブロッキング指摘なし。巨大角度の正規化はループを使わない演算へ修正し、無限値拒否/未知コマンド拒否を追加検査した。

全体・日本語UI・木床/壁・ソファの実表示、ドラッグ/Ctrl+Z・Y/部屋描画/床交換/数値入力/クリック配置/保存・GUI再起動を配布exeの実画面で確認。同一フレームの押下・移動・解放で旧BindKey経路が終点座標/解放済み修飾キーを参照する不具合をログで確認したため、離散入力はInputKeyでイベント順に処理する。旧割当と重複関数は削除し、解放時の終点確定とフォーカス喪失時の取消を実装。`artifacts/native-desktop-validation.md` に根拠と保全を記録。右ドラッグの実入力/全体の性能・写実受入は未確認。ビルドは -NoUBA を使用。
