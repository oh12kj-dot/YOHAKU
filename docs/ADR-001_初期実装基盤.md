# ADR-001 初期実装基盤

2026-11-08: 技術基盤は[ADR-003](ADR-003_UE5ネイティブアプリ.md)へ置換。以下は旧Web版の判断記録であり現行構成ではない。

日付: 2026-11-07 / 状態: 開発基盤のみ採用。レンダラー・外部サービスの正式採用は保留。

## 決定

基本設計1.5・詳細設計1.1の既定境界を使用し、React/TypeScript/Viteの単一開発環境に、contracts、scene-domain、geometry-kernelを分離する。Three.jsをRendererAdapter内に閉じ込める。API・永続化・取得/生成は未接続のまま、それらが動作したような成功応答や商品を画面に作らない。

詳細設計19章の最初の実商品縦断検証は未実施。生成先、公式資料の評価対象、校正済みQualityProfileが存在せず、現時点で縦断合格を示せない。既定インターフェース内の初期実装を先行し、商品連携を有効にする前に縦断検証へ戻る。要件を緩めた完成判定は行わない。

## 依存関係

2026-11-07にnpm registryで取得。再現用の正確な全バージョンは`package-lock.json`に固定する。Node 24.15.0 / npm 11.12.1で実行。

React 19.3.1、Three.js 0.187.0、Vite 8.3.6、TypeScript 7.0.2、Zod 4.6.7を使用。Zodは依存監査で検出したGHSA-mrhx-c7xc-m3w5の修正を含む版へ更新した。

公式情報確認先:

- [React Versions](https://react.dev/versions)
- [Vite Getting Started](https://vite.dev/guide/): Node対応要件を確認
- [Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer): WebGL2、描画基盤
- [Three.js Migration Guide](https://github.com/mrdoob/three.js/wiki/Migration-Guide): 版変更時の確認先

## 実装上の境界

- `SceneDraft`はRoom/家具/幾何警告のみ。窓・ドア・素材編集・環境保存・保存視点はまだ実装していない。
- 部屋寸法の初期値は仮値。家具外寸はアセット参照から読み、配置側にサイズ/拡縮を持たせない。
- `applyCommand`は純粋処理で、認証主体やトランザクションを保証しない。将来のSceneApplicationは所有権、現在ポリシー、利用権をDBでロックして再検査する必要がある。
- `Envelope`のスキーマはあるが、版管理・操作台帳・DB保存・Undo/Redoは未実装。revisionを発行したように見せない。
- 当面はタブ内メモリーのみ。IndexedDBキューとサーバーが未接続のため保存済み表示は設けない。
- 開発上限: 部屋各軸30,000mm、座標±100,000mm、家具200点、柱100点。校正済みResourceProfileではなく、正式提供値ではない。
- 衝突判定は床置き家具のOBB/SATによる「候補」。詳細メッシュ干渉・距離・ドア掃引は未実装。
- 描画は標準素材による部屋の基礎表示。北(z=0)・西(x=0)壁のみ表示する一時カットアウェイ。画像ベース照明、実商品素材、写実品質/操作性能の受入は未実施。
- ビルドは成功するが、Three.jsを含む約877KBの単一JSにViteのサイズ警告がある。実アセット導入時に読込と描画の計測・分割を行う。

## 次の受入境界

実商品縦断検証には、利用可能な公式商品URLと資料・画像の取得条件、OCR/解析/3D生成先の契約と試験認証情報、校正評価集合、基準端末が必要。認証/DB/ストレージは別途、設計のロール・RLS・非公開配信・復旧要件を実環境で満たす必要がある。
